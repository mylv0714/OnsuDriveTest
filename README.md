# DriveTassist — 온수 도로주행 연습

온수역자동차전문학원 도로주행 **A·B·C·D 코스**(학원 도로주행코스도 2026.07.03판)를 3D로 옮긴 브라우저 연습 시뮬레이터입니다.
다른 차량과 횡단보도 보행자가 함께 움직이고, 좌회전 화살표가 있는 신호등이 주기에 따라 바뀝니다.
도로 형태(철길 방음벽, 오류철도고가 3거리, 중앙분리대 형태, 버스전용차로, 제한속도 구역, U턴 보조판)는 학원 코스 주행 영상을 보고 맞췄습니다.

## 실행

ES 모듈을 쓰므로 로컬 서버가 필요합니다 (Three.js는 CDN에서 불러옵니다).

```bash
python -m http.server 8123
```

브라우저에서 http://localhost:8123 을 열고 코스를 고릅니다.

## 조작

| 키 | 기능 |
|---|---|
| E | 가속 |
| W | 브레이크 |
| ← → | 핸들 |
| 1 / 2 | 좌 / 우 방향지시등 (회전 후 핸들을 풀면 자동 해제) |
| D / R / N | 기어 주행 / 후진 / 중립 (언제든 바로 변경 — 주행 중 R이면 감속 후 후진) |
| C | 운전석 ↔ 3인칭 시점 |
| M | 전체 지도 |
| T | 마지막 체크포인트로 복귀 |
| V | 음성 안내 켜기/끄기 |

출발 시 기어는 N입니다. D로 바꾸고 출발하세요.

## 채점 (연습용 간이 기준)

- 실격: 신호위반, 중앙선 침범, 코스 이탈, 차량·보행자 사고, 횡단 중인 보행자가 있는 횡단보도 진입,
  유턴 금지 장소 유턴, 보조판(보행신호시) 조건 위반 유턴, 오류철도고가 3거리 우회전 시 일시정지 불이행(우회전 신호 24시간 적색)
- 감점: 속도위반(제한속도 +20km/h 이상 — 50 구간 70, 30 구간 50), 방향지시등 미작동(출발·회전·차로변경·유턴),
  지정차로 위반(좌회전은 1차로/좌회전 전용차로, 우회전은 끝 차로, 유턴은 유턴 전용차로, 좌회전 전용차로 직진 금지),
  적색 신호 우회전 시 일시정지 불이행, 진로변경 제한선 위반, 정지 5초 이상 D 기어 유지(N 미전환) 5점, 연석·보도 침범, 구조물 충돌
- 70점 이상 합격

## 구성

- `js/map.js` — 안내도 픽셀 좌표로 옮긴 도로망·건물 데이터 (1px = 3m)
- `js/course.js` — 코스별 경로와 구간 안내
- `js/net.js` — 도로망 기하 (차로, 교차로, 입체교차 높이)
- `js/terrain.js` — 지형 (도로의 완만한 오르내림, 도로에서 떨어진 언덕·산)
- `js/world.js` — 도로·차선·신호등·건물·철도·고가차도·오류IC 등 3D 생성
- `js/signals.js` — 신호 주기 (좌회전 화살표, 전적색 포함)
- `js/traffic.js`, `js/peds.js` — 다른 차량, 보행자
- `js/game.js` — 진행·채점, `js/car.js` — 차량, `js/hud.js` — 화면 표시, `js/main.js` — 메인 루프
